# 1. 简介

sloth-lang 2.0（下称 **sloth2**）是 sloth-lang 1.0 的静态强类型重写版。1.0 是
"one-pass 解析直出字节码 + 栈式虚拟机 + 全值装箱 + 标记清理 GC"的解释器；
2.0 用 **Rust 前端 + MLIR/LLVM 后端**替换了整条链路，并引入静态类型系统。

## 1.1 设计目标

1. **静态强类型**：类型在编译期确定或局部推断，消除隐式类型变化；动态能力
   收敛到显式的 `dyn Trait`。
2. **AOT 编译**：源码 → MLIR → LLVM → 原生机器码，性能目标为数量级提升。
3. **语义一致性**：基础类型与类实例遵循统一的类型规则。
4. **语法延续**：保留 C-like 语法外壳与核心惯用法（管道 `|>`、字符串插值、
   迭代器 for、运算符重载）。
5. **可实现的运行时**：核心语言不含协程/线程原语，运行时收敛为内存管理（ARC）、
   字符串（堆分配，非驻留）、容器、IO/FFI 四块。

协程（`fiber.*`）、OS 线程（`thread.*`）、张量（`tensor.*`）与 I/O 事件队列
（`io.*`/`net.*`）以**扩展模块**形式在核心之上实现：它们复用普通函数调用语法，
不新增语言关键字（见第 25–29 章）。

非目标：与 1.0 源码兼容；核心语言内建的线程/并行原语；宏、async/await、类型类；
首版不做增量编译与语言服务器。

## 1.2 相对 1.0 的关键差异

| 维度 | 1.0 | 2.0（当前实现） |
| --- | --- | --- |
| 执行 | 栈式 VM 解释 | MLIR → LLVM JIT / 原生可执行 |
| 类型 | 运行时动态 | 编译期静态 + 局部推断 |
| 值表示 | 全装箱 `Value` | **无 tag 的单 i64 词面**（引用=裸指针，数值=原生位模式；见 §5） |
| 内存 | mark & sweep GC | **ARC 引用计数** + `Weak<T>` 破环 |
| 可空 | 任意值为 `nil` | 仅 `T?` 可为 `nil`，用前须收窄 |
| 布尔 | 任意值隐式转 bool | 仅 `bool` 可作条件 |
| 数值 | 仅 f64 | `int`（64-bit）/ `float`（f64）+ 定宽有/无符号族，无隐式互转（§5） |
| 模块 | 运行时 `import()` | 编译期 `import "x.sl"` + `pub` |
| 协程 | `fiber.*` | 核心语法移除；经 `fiber.*` 扩展模块回归（§27） |

## 1.3 当前状态

语言特性面已基本对齐设计目标：类型系统（含定宽/无符号整数）、泛型单态化、
类/继承/虚分派、trait/`dyn`、闭包与一等函数、容器、可空类型、`Result`、迭代协议、
编译期模块、FFI 与 ARC 均已落地；张量、协程、多线程与 I/O 扩展（§25–§29）亦已
可用。工程面有两处与设计文档的**结构性偏差**，属定案取舍：

- **没有独立的名称解析/类型检查两遍阶段**：解析后由单一发射器在生成 MLIR 的
  过程中完成符号收集、局部推断与约束检查。
- **`sloth` 自定义 dialect 仅为最小语义层**：ARC 的 `retain`/`release` 以
  `sloth.rc_retain`/`sloth.rc_release` 发射，随后在同一次编译内**单点 lowering**
  为标准 dialect（`func.call @__sloth_rc_*`）。对外 IR（`slothc ir`、AOT、本书
  示例）不含 `sloth.*`；设计稿中的完整类型/GC 方言（`!sloth.string`、
  `sloth.gc_alloc` 等）不实现。
