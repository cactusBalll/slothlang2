# 7. 运算符与表达式

## 7.1 运算符一览

| 类别 | 运算符 | 说明 |
| --- | --- | --- |
| 算术 | `+ - * / %` | 两侧同型；整数除法向零截断；除/模零 panic |
| 位运算 | `& \| ^ << >>`、一元 `~` | **仅整数**；移位与比较按有无符号选择 `shrui`/`shrsi` 等（见 §5.6） |
| 一元 | `-`、`not`、`~` | `-` 支持用户 `__neg__` |
| 复合赋值 | `+=`、`-=` | 语句级，`x op= y` ≡ `x = x op y`；左值只求值一次（§6.1） |
| 比较 | `> >= < <= == !=` | 词比较；类需重载（见 §20） |
| 逻辑 | `and` / `&&`、`or` / `||` | **短路**求值 |
| 范围 | `..`（半开）、`..=`（闭） | 类型 `range`，元素 `int` |
| 类型测试 | `is`、`is not` | 结果为 `bool`，并触发收窄（见 §15/§18） |
| 空合并 | `?:`（Elvis） | `lhs is nil` 时取 `rhs` |
| 管道 | `\|>` | `x \|> f` ≡ `f(x)`；`x \|> f(a)` ≡ `f(a, x)`（追加为**末参**） |

**没有隐式数值转换**：`1 + 2.5`、`3.0 == 3` 都是编译错误，需显式 `float(1)` /
`int(3.0)`。`str + str` 是内置**拼接**；`Array<T>` **没有** `+` 运算，拼接请用
标准库 `array_concat` / `array_extend`（§12.4）。定宽整数之间也需显式转换。

## 7.2 优先级（低 → 高）

```text
|>      (最低，左结合链)
?:      (右结合)
or  ||  (左结合)
and &&
== != < > <= >=  is  is not
|       (按位或)
^       (按位异或)
&       (按位与)
<<  >>  (移位)
..  ..=
+  -
*  /  %
一元 -  not  ~
调用/索引/字段 . [] ()
```

位运算优先级与设计 §3.3 一致：移位比 `+`/`-` 松、比 `&` 紧，且 `&` 紧于 `^`、
`^` 紧于 `|`（例如 `1 + 2 << 3 == 24`、`5 & 3 | 8 == 9`）。复合赋值是语句而非
表达式，不参与该表。

## 7.3 短路与除零

- `a and b` / `a or b` 编译为**控制流**（`cf.cond_br`），右侧不满足条件时不求值；
  守卫惯用法 `i < len and a[i] == x` 因此安全。
- 整数 `x / 0`、`x % 0` 在发射期插入零值守卫，命中则走运行时
  `__sloth_panic_divzero`（打印诊断并退出）。

要点：

- `|>` 只是语法糖：`5 |> double` 直接发射 `call @sloth_main__double(%c5_i64)`
  （去 tag 后 5 就是原生 i64）；`2 |> double |> double` 左结合为两层调用。
- `?:` 对值型 `int?` 会先做 nil 判定：`arith.cmpi ne, %w, 0`，非 nil 分支
  `__sloth_box_get` 解出 payload。
- `is` 对基础类型词面的测试在编译期即可裁定（如已知类型为 `str` 时 `x is int` 为
  `false`）；对类的 `is`（含 `dyn`）用运行时 class-id 判定。
- 字面量范围 `0..3` 在 `for` 头里被**内联为计数循环**（边界是常量，直接比较），
  不建盒；只有作为**一等值**出现（赋给变量、传参、返回）时才发射
  `__sloth_range_pack`，迭代时用 `__sloth_range_lo`/`__sloth_range_hi` 取边界。
