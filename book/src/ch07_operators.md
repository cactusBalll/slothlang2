# 7. 运算符与表达式

## 7.1 运算符一览

| 类别 | 运算符 | 说明 |
| --- | --- | --- |
| 算术 | `+ - * / %` | 两侧同型；`int` 除法向零截断；除/模零 panic |
| 一元 | `-`、`not` | `-` 支持用户 `__neg__` |
| 比较 | `> >= < <= == !=` | 词比较；类需重载（见 §20） |
| 逻辑 | `and` / `&&`、`or` / `||` | **短路**求值 |
| 范围 | `..`（半开）、`..=`（闭） | 类型 `range`，元素 `int` |
| 类型测试 | `is`、`is not` | 结果为 `bool`，并触发收窄（见 §15/§18） |
| 空合并 | `?:`（Elvis） | `lhs is nil` 时取 `rhs` |
| 管道 | `\|>` | `x \|> f` ≡ `f(x)`；`x \|> f(a)` ≡ `f(a, x)`（追加为**末参**） |

**没有隐式数值转换**：`1 + 2.5`、`3.0 == 3` 都是编译错误，需显式 `float(1)` /
`int(3.0)`。字符串/数组的 `+` 是内置拼接。

## 7.2 优先级（低 → 高）

```text
|>      (最低，左结合链)
?:      (右结合)
or
and
== != < > <= >=  is  is not
..  ..=
+  -
*  /  %
一元 -  not
调用/索引/字段 . [] ()
```

## 7.3 短路与除零

- `a and b` / `a or b` 编译为**控制流**（`cf.cond_br`），右侧不满足条件时不求值；
  守卫惯用法 `i < len and a[i] == x` 因此安全。
- 整数 `x / 0`、`x % 0` 在发射期插入零值守卫，命中则走运行时
  `sloth_panic_divzero`（打印诊断并退出）。

要点：

- `|>` 只是语法糖：`5 |> double` 直接发射 `call @sloth_main__double(%enc(5))`；
  `2 |> double |> double` 左结合为两层调用。
- `?:` 对值型 `int?` 会先做 nil 判定：`arith.cmpi eq, %w, 0`，非 nil 分支
  `sloth_box_get` 解出 payload。
- `is` 对基础类型词面的测试在编译期即可裁定（如已知类型为 `str` 时 `x is int` 为
  `false`）；对类的 `is`（含 `dyn`）用运行时 class-id 判定。
- 字面量范围 `0..3` 在 `for` 头里被**内联为计数循环**（边界是常量，直接比较），
  不建盒；只有作为**一等值**出现（赋给变量、传参、返回）时才发射
  `sloth_range_pack`，迭代时用 `sloth_range_lo`/`sloth_range_hi` 取边界。
