# Change Log

All notable changes to the "slothlang2-syntax" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

## [0.1.0]

- Full TextMate grammar covering SlothLang 2 keywords, declarations, types,
  literals, operators and punctuation.
- Double-quoted strings with escape sequences and recursive `${expr}`
  interpolation highlighting.
- Line (`//`) and block (`/* */`) comment highlighting.
- Register `.sl` source files in addition to `.slt` module files.
- Language configuration: bracket matching, auto-closing/surrounding pairs,
  comment toggling and indentation rules.

## [0.0.1]

- Initial generated stub (keywords `if`/`while`/`for`/`return` and strings).
